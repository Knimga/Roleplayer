# Weapon Damage Reference (NPC Damage Rolls)

On a successful enemy hit, roll the weapon's damage dice via the dice tool. Damage is a flat dice value by weapon class — NOT modified by any STAT. Pick a weapon that fits the enemy's concept, roll its dice, and read the total to advance the target's wound narration (players apply the number to their own HP).

## Ranged Weapons

| Weapon | Damage | Notes |
|---|---|---|
| Medium Pistol | 2d6 | Common sidearm; concealable. |
| Heavy Pistol | 3d6 | Standard tough-guy handgun. |
| Very Heavy Pistol | 4d6 | Hand cannon; hits hard, not concealable. |
| SMG | 2d6 (single shot) | Concealable spray weapon. |
| Heavy SMG | 3d6 (single shot) | |
| Shotgun | 5d6 (slug) | Brutal up close. |
| Assault Rifle | 5d6 (single shot) | Standard soldier/merc long gun. |
| Sniper Rifle | 5d6 | Long-range precision. |
| Bow / Crossbow | 4d6 | Quiet; used by scavs and road gangers. |
| Grenade Launcher | 6d6 | Explosive (hits an area). |
| Rocket Launcher | 8d6 | Explosive (hits an area). |

## Unarmed

- Brawling / martial arts — scales with the attacker's build; use 1d6 for an ordinary bruiser, 2d6 for a big or cybered-up enemy, 3d6 for a monster. (Fists don't ignore armor.)

## Typical Weapon by Enemy Tier (suggestions, not rules)

| Tier | Typical weapon |
|---|---|
| Untrained | Light melee (1d6) or a medium pistol (2d6). |
| Mook | Medium/heavy pistol (2d6-3d6), SMG (2d6), or a bat (2d6). |
| Professional | Heavy pistol (3d6), shotgun (5d6), or assault rifle (5d6). |
| Elite | Very heavy pistol (4d6), assault rifle (5d6), or heavy melee (3d6). |
| Boss | Assault rifle/shotgun (5d6), heavy weapons (6d6-8d6), or very heavy melee (4d6). |

## Narration Note

Read the damage roll's size, not just the fact of a hit: a low roll grazes or is soaked by armor (nudge status slightly), a high roll tears through (jump the target up the bruised->dead ladder). Fold the number into the description rather than announcing it dryly.
